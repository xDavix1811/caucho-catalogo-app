# Caucho Catálogo — baixar o app

App de consulta do catálogo da **Caucho Borrachas**: elementos elásticos, coxins e amortecedores para rolos compactadores e tratores.
Busca pelo código Caucho ou OEM e pelo número de série do equipamento. Funciona sem internet.

## 📱 Android

**[Baixar o app para Android (APK)](https://github.com/xDavix1811/caucho-catalogo-app/releases/latest/download/caucho-catalogo.apk)**

Toque no arquivo baixado para instalar. Na primeira vez o celular pede para permitir "instalar apps desta fonte": é só permitir.
Funciona a partir do Android 7.

## 💻 Windows

**[Baixar o instalador para PC (.exe)](https://github.com/xDavix1811/caucho-catalogo-app/releases/latest/download/caucho-catalogo-instalador.exe)**

Abra o arquivo baixado. Se o Windows mostrar "O Windows protegeu o computador", clique em **Mais informações → Executar assim mesmo**.
